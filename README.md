# Капибанк

Кредитный кабинет для бизнеса: подбор продуктов, сравнение условий, заявки, рассмотрение сотрудником и помощник Капибанкир на GPT OSS 120B через Groq.

## Запуск

Нужны Docker Engine или Docker Desktop и интернет для загрузки зависимостей и работы помощника.

```sh
cp .env.runtime.example .env.runtime
```

Если `.env.runtime` уже существует, сохраните его. В этом файле заполните `GROQ_API_KEY` и задайте собственные `SECRET_KEY` и `POSTGRES_PASSWORD`. Модель `openai/gpt-oss-120b` и режим `LLM_MODE=groq` уже указаны в примере. Ключ используется только сервером. Для работы без модели явно выберите `LLM_MODE=stub`.

```sh
docker build -t kapibank .
docker run -d --name kapibank -p 127.0.0.1:8080:8080 --env-file .env.runtime -v kapibank-data:/var/lib/postgresql/data kapibank
```

Откройте http://localhost:8080. Описание API доступно на `/docs`, проверка готовности приложения и БД - на `/health`. Если порт занят, измените левую часть, например на `8082:8080`.

В опросе на шаге суммы спросите Капибанкира: «Нужно полтора миллиона». Помощник должен предложить `1500000.00`; поле изменится только после подтверждения. На шаге срока проверьте «Два года». Если ключ отсутствует или Groq отклоняет запрос, чат покажет ошибку; основной путь работы с заявками остаётся доступным.

В текущей поставке используются учебные данные и моделирование банковских операций. Приложение не выдаёт реальные кредиты, не переводит деньги и не выполняет юридически значимое подписание.

## Данные и обновления

Данные сохраняются в volume `kapibank-data`. При обновлении пересоберите образ и пересоздайте контейнер с тем же volume. Новые значения из `.env.runtime` применяются при пересоздании, обычного перезапуска недостаточно. Не запускайте два контейнера с одним volume одновременно.

Исходники интерфейса находятся в `src/`, сервер - в `kapibank-backend/`, изображения и лицензии - в `assets/` и `public/`. Материалы, которые не нужны для запуска, собраны в [development/](development/README.md).
