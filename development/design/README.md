# Палитра Капибанка

Статическая демонстрация палитры находится в `development/design/palette.html`. Откройте её напрямую или из корня проекта запустите локальный сервер:

```sh
python3 -m http.server 8081 --bind 127.0.0.1
```

Адрес страницы: http://127.0.0.1:8081/development/design/palette.html

## Направление

Тёплая бумага, кофейный текст, карамельный маскот и шалфейные действия. Демонстрация показывает палитру, пример заявки и таблицу контраста. Примеры не выполняют банковские операции.

Для самой страницы используются обычный CSS и семантические переменные. Цвета заданы в sRGB HEX для воспроизводимого APCA; рядом указана эквивалентная запись OKLCH. Радиусы: 12px для контролов, 24px для крупных поверхностей и pill для статусов.

Демонстрационная страница использует системный Trebuchet MS с системными запасными шрифтами. Приложение использует локальный Nunito Sans Variable. Таблица fontLookupAPCA даёт общую рекомендацию и не сертифицирует отдельные гарнитуры.

## Воспроизводимая проверка

Из корня проекта установите отдельные зависимости и запустите расчёт:

```sh
npm ci --prefix development/tools/palette
node development/tools/palette/check.mjs
```

Результат сохраняется в `development/design/palette-report.json`. При нарушении проектного порога или минимального размера из fontLookupAPCA скрипт завершается с кодом 1. Lc сравнивается до округления, знак полярности сохраняется в отчёте.

Проектные пороги: |Lc| ≥ 90 для основного текста 16px/400; ≥ 75 для подписей, вторичного текста, основной кнопки и статусов; ≥ 60 для короткого полужирного текста 18px на тёплых акцентных подложках. Для каждого случая дополнительно проверяется таблица размеров и весов APCA. Это правила проекта, а не универсальные уровни APCA-сертификации.

Исходную карамель #D5A06A используем для декора. Для текста предусмотрена светлая карамель #EAC9A2. Перед изменением подложек повторите расчёт.

APCA остаётся развивающейся методикой. Проверка девяти пар не подтверждает соответствие всего приложения WCAG 2.2 и не охватывает нетекстовые контролы.

Источники:
- https://github.com/Myndex/apca-w3
- https://apcaw3.myndex.com/docs/APCA-W3_FunctionsOverview.html

При изменении палитры синхронизируйте `development/tools/palette/check.mjs`, `src/tokens.css` и демонстрационную таблицу в `development/design/palette.html`, затем повторите расчёт.
