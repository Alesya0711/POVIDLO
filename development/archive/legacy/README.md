# Демонстрация кредитного кабинета

Откройте `index.html` двойным кликом в браузере. Установка зависимостей и сборка не нужны. Интерфейс работает без внешних ресурсов и интернета.

Если браузер ограничивает сохранение локальных HTML-файлов, запустите из папки проекта:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Затем откройте <http://127.0.0.1:8080>. Данные хранятся в localStorage конкретного браузера и адреса: локальный файл и сервер имеют отдельное хранилище.

## Что попробовать

1. Нажмите «Новая заявка», выберите оборотный кредит.
2. Пройдите три шага формы с готовыми вымышленными данными или измените их. Черновик сохраняется при изменении полей и переходе между шагами.
3. Отправьте заявку: через несколько секунд появится решение. С исходными данными получится одобрение.
4. Нажмите «Открыть кабинет банка»: появятся скоринговый балл, факторы и результаты имитации проверок.
5. В очереди банка нажмите «Пример для рассмотрения». Можно одобрить, отказать или запросить сведения.
6. После запроса переключитесь в роль предпринимателя, откройте заявку и дополните данные. При повторной отправке сохранится номер и история заявки.
7. Обновите страницу: сохранённые заявки останутся в кабинете.

Чтобы увидеть автоматический отказ, создайте ещё одну заявку и укажите наличие просрочек. Бизнес младше 24 месяцев при приемлемой оценке направляется сотруднику. Меняйте доходы, расходы и платежи по кредитам, чтобы увидеть влияние на скоринг.

## Как устроено демо

- Один HTML-файл с обычными CSS и JavaScript, без сторонних библиотек.
- Форма, проверки ввода, список заявок, история, фильтр и поиск в банковской очереди.
- Объяснимая балльная модель: исходный балл 78; возраст бизнеса, покрытие платежа свободным доходом и просрочки меняют его. Результат ограничен диапазоном 0–100.
- Скоринг оценивает риск, а отдельные правила определяют исход. Например, молодой бизнес требует ручного рассмотрения даже при высоком балле.
- Примерный аннуитетный платёж рассчитан по вымышленной ставке 22,5% годовых. Комиссии и страховки не моделируются.

Это минимальный интерактивный макет для обсуждения продукта, а не готовое решение для сдачи. Бэкенд, настоящая авторизация, Docker, внешние интеграции, документы и выдача денег не реализованы. Проверки имитируются в браузере; переключатель роли доступен всем. Все условия и данные демонстрационные. Исходные значения находятся в `defaultData()`, правила — в `score()` и `outcome()`, цвета — в CSS-переменных `:root`.
